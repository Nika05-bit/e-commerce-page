🛍 E-Commerce Product Page

A responsive e-commerce product page built with HTML, CSS, and JavaScript.
The project showcases a product gallery with thumbnails, a lightbox modal, a shopping cart preview, and mobile navigation.

⸻

🚀 Features
	•	Responsive Layout – works on desktop and mobile.
	•	Product Image Gallery – click thumbnails to change the main product image.
	•	Lightbox Modal – view large product images with next/prev navigation.
	•	Cart Functionality – add/remove items, update quantity, live price calculation.
	•	Cart Preview Dropdown – quick view of cart items before checkout.
